# wiki/concepto/ — Páginas de conceptos

Ideas, fenómenos, metodologías y términos importantes para la investigación. Un
concepto merece página propia cuando aparece repetidamente en varias fuentes o es
central en la investigación.

**Normas (ver `AGENTS.md`):**
- Nombre legible: `concepto/Capital cultural.md`
- Frontmatter YAML completo (tipo `concepto`, creado, actualizado, fuentes).
- Todo en español, con enlaces `[[...]]` a entidades y otros conceptos.
- Plantilla: [[_templates/concepto]]
