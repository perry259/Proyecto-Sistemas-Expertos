# wiki/entidad/ — Páginas de entidades

Personas, organizaciones, lugares, sistemas, experimentos, datasets u obras que
aparecen de forma sustancial en las fuentes.

**Normas (ver `AGENTS.md`):**
- Nombre legible: `entidad/Pierre Bourdieu.md`
- Frontmatter YAML completo (tipo `entidad`, creado, actualizado, fuentes).
- Todo en español, con enlaces `[[...]]` a conceptos y otras entidades.
- Plantilla: [[_templates/entidad]]

El LLM crea una entidad cuando una fuente la menciona de forma sustancial, y la
actualiza cuando nuevas fuentes aportan información.
